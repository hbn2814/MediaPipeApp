# MediaPipe 학교 탐구 앱

구글 **MediaPipe**로 만드는 교실용 AI 탐구 앱 모음입니다.
설치 없이 브라우저에서 바로 동작하고, 카메라 영상은 컴퓨터 밖으로 보내지 않습니다.

**바로 열기:** <https://hbn2814.github.io/MediaPipeApp/>

| 폴더 | 내용 | 상태 |
|---|---|---|
| [plan/](plan/) | 학생과 함께 고르는 프로젝트 기획안 (4개 분야, 15개 프로젝트) | 의견 모으는 중 |
| [games/](games/) | 게임 코너: 과일 닌자, 벽 통과 챌린지, 손 탁구 대결, 표정 챌린지, 거꾸로 가위바위보 | 완성 |
| [project1/](project1/) | 규칙 기반 입문 앱: 손가락 퀴즈, 스쿼트 카운터, 집중 타이머 | 완성 |
| project2/ ~ project5/ | 보건 · 환경 · 학습 · 독서 분야 앱 | 기획 단계 |

## 개인정보 원칙

- 모든 AI 계산은 브라우저 안에서 이루어지고, 영상·사진·녹음은 저장하거나 전송하지 않습니다.
- 학생 데이터(수집 기록 CSV, 학습용 사진 등)는 이 저장소에 올리지 않습니다.

## 로컬에서 실행하기

카메라는 `https://` 또는 `http://localhost` 주소에서만 켜집니다.
VS Code의 **Live Server**나 `python -m http.server 5500`으로 이 폴더를 열어 주세요.
자세한 내용은 [project1/README.md](project1/README.md)에 있습니다.
