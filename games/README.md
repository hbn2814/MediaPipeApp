# 🎮 게임 코너

준비물 없이 카메라만 켜면 바로 하는 MediaPipe 게임 10가지입니다.
데이터 수집이나 티처블 머신 학습 없이 **MediaPipe + 게임**만 사용합니다.

| 게임 | MediaPipe | 인원 | 핵심 원리 (`rules.js`) |
|---|---|---|---|
| [✂️ 과일 닌자](fruit-ninja/) | 손 (검지 끝) | 1명 | 손끝 속도로 "베기" 판단, 선분과 원의 충돌 판정, 포물선 운동 |
| [🧱 벽 통과 챌린지](hole-wall/) | 몸 (점 33개) | 1명씩 | 팔다리 방향(각도) 비교: 키가 달라도 공평하게 |
| [🏓 손 탁구 대결](hand-pong/) | 손 2개 | 2명 / 컴퓨터 | 화면 좌우로 선수 나누기, 반사각, 떨림 줄이기 |
| [😜 표정 챌린지](face-challenge/) | 얼굴 (표정 점수 52개) | 1명 | 표정 점수 조합과 기준값 |
| [✊ 거꾸로 가위바위보](reverse-rps/) | 손 | 1명 | project1 손가락 규칙 재사용, 승부 계산 |
| [🪂 고개 비행기](head-plane/) | 얼굴 (두 눈 끝) | 1명 | 두 점을 잇는 선의 기울기(각도), 떨림 없는 구간 |
| [🎨 공중 그림 퀴즈](air-draw/) | 손 (검지 끝) | 모둠 | 손 모양으로 펜 상태 바꾸기, 손떨림 줄이기 |
| [🎈 풍선 팡팡](balloon-pop/) | 몸 (손·머리·발) | 1명 | 부위별로 터뜨릴 수 있는 풍선, 거리로 닿음 판단 |
| [🧊 얼음 땡](freeze-dance/) | 몸 (최대 5명) | 여러 명 | 기준 자세와 비교, 몸통 길이로 나누기, 사람 짝짓기 |
| [🔢 순서대로 집게](pinch-order/) | 손 (엄지·검지) | 1명 | 손 크기 대비 거리로 집기 판단, 두 기준으로 떨림 막기 |

## 폴더 구조

```
games/
├─ index.html          게임 목록
├─ shared/
│  ├─ engine.js        공통 뼈대: 카메라 → AI 모델 → 매 프레임 frame() 호출, 화면 그리기 도구
│  ├─ sound.js         효과음과 음악 (소리 파일 없이 브라우저가 직접 만듦)
│  ├─ body.js          여러 게임이 함께 쓰는 몸 규칙 (양손 들기)
│  └─ game.css         공통 화면 스타일
├─ <게임>/
│  ├─ index.html       화면
│  ├─ app.js           게임 진행과 그리기
│  └─ rules.js         ★ 규칙과 숫자 (학생이 고쳐 볼 곳)
└─ tests/games.test.js 규칙 자동 테스트
```

## 원칙

- 영상과 점수는 저장하거나 전송하지 않습니다. "오늘의 최고" 기록은 새로고침하면 사라집니다.
- 순위는 그날의 기록으로만 보여 줍니다. 몸을 쓰는 게임에는 앉아서 하는 방법도 있습니다.

## 규칙 테스트 (선택)

Node.js가 설치되어 있으면 카메라 없이 규칙을 검사할 수 있습니다.

```bash
cd games
npm test
```
